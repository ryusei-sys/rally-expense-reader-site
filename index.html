Rally Expense Reader

A private, read-only QuickBooks expense-review tool for Rally Essentials’ authorized company administrator.

It helps review software spending, recurring charges, and possible duplicate or unusual expenses. It does not change bookkeeping entries, make payments, cancel subscriptions or send messages.

Connection status

Development testing is complete. Live-company access remains pending Intuit production approval and a separate owner-authorized connection.

These public pages contain app information only. No bookkeeping data, API keys, OAuth tokens or transaction-reading endpoints are hosted here.
